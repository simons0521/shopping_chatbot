🛒 Shopping Chatbot - 智能电商客服系统
一个基于 LangGraph 和 RAG（检索增强生成） 技术的智能电商客服聊天机器人，能够处理订单查询、FAQ 问答、退款申请、商品推荐等多种客服场景。
✨ 核心特性
🤖 智能意图识别：基于 LLM 的意图识别系统，自动判断用户问题类型（订单查询/FAQ/退款/商品推荐）
📚 RAG 知识库：使用 Chroma 向量数据库存储 FAQ 知识，支持语义相似度检索，准确回答常见问题
🔧 多工具协同：集成订单查询、订单列表、退款申请、商品搜索等多个工具函数
💬 会话记忆：支持多轮对话上下文管理，保持对话连贯性
🌐 Web 界面：基于 FastAPI + Jinja2 的友好 Web 交互界面
📊 日志记录：自动记录用户问题和系统回答，便于后续分析和优化
🐳 Docker 支持：提供完整的容器化部署方案
🏗️ 技术架构
用户提问 → 意图识别 → 工具路由 → 工具执行 → 结果返回
              ↓
         LangGraph 状态图工作流
🛠️ 技术栈
框架：FastAPI, LangGraph, LangChain
向量数据库：Chroma
LLM：DeepSeek / OpenAI compatible
Embedding：DashScope (阿里云通义千问)
前端：Jinja2 模板引擎
部署：Docker
